# Brand icons

Visa, Mastercard and JCB SVG artwork is from [SVG Credit Card & Payment Icons](https://github.com/aaronfagan/svg-credit-card-payment-icons), using the color `logo` variants under Apache-2.0. The license is retained in `third-party/payment-icons-LICENSE.txt`.

Local files: `public/icons/visa.svg`, `public/icons/mastercard.svg`, `public/icons/jcb.svg`.

Changes: view boxes cropped to the artwork; intrinsic dimensions removed for proportional scaling. Mastercard orange normalized to `#FF5F00`, matching the [brand color specifications](https://www.mastercard.com/brandcenter/us/en/brand-requirements/mastercard.html). The UI uses equal-size light containers, preserving each logo's proportions. Brand names retain the shared text color.

The GitHub SVG (`public/icons/github.svg`) is from [Simple Icons](https://github.com/simple-icons/simple-icons), under CC0, with a light monochrome fill.
